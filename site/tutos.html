1. Installer l'appli

5 minutes · un téléphone Android compatible ARCore.

  1. Vérifier le téléphone. La plupart des Android récents de milieu et haut de gamme sont compatibles. Liste officielle : developers.google.com/ar/devices.
  2. Télécharger l'APK depuis l'accueil du portail : scanner le QR code avec l'appareil photo, ou ouvrir la page sur le téléphone et toucher ⬇ AtelierRA.apk.
  3. Ouvrir le fichier téléchargé (notification de téléchargement, ou appli « Fichiers » → Téléchargements).
  4. Autoriser l'installation. Android bloque d'abord : toucher Paramètres, activer Autoriser cette source pour le navigateur, puis revenir en arrière.
  5. Play Protect peut signaler une « appli inconnue » : c'est normal, elle ne vient pas du Play Store. Toucher Plus de détails → Installer quand même.
  6. Premier lancement : accepter l'installation de Services Google Play pour la RA si elle est proposée, puis l'accès à la caméra.
L'appli n'est pas publiée sur le Play Store : c'est un prototype de R&D, distribué directement depuis ce portail.

2. Imprimer et poser les marqueurs

Le marqueur dit à l'appli « tu es devant telle machine, à tel endroit ».

  1. Imprimer à 100 % (taille réelle) la planche PDF. Dans la fenêtre d'impression, désactiver « Ajuster à la page ». Vérifier à la règle : 8 cm pour la table et le bureau, 12 cm pour la PolyProd.
  2. Papier mat, ou plastification mate : les reflets empêchent la détection.
  3. Coller bien à plat, à l'endroit indiqué sur la planche, bandeau noir « HAUT » dans le bon sens.
  4. Ne jamais dupliquer un marqueur sur deux machines : chaque image est unique et désigne un seul endroit.

3. Premier lancement

  1. Balayer doucement la pièce quelques secondes : le téléphone apprend l'espace autour de lui.
  2. Approcher le marqueur jusqu'à ce qu'il occupe environ un quart de l'écran (≈ 25 cm pour 8 cm, ≈ 40 cm pour 12 cm).
  3. Le cadre apparaît sur le marqueur et la fiche s'ouvre en bas de l'écran. Vous pouvez ensuite reculer et tourner autour de la machine.

4. La fiche et ses onglets

« Masquer ▾ » cache la fiche ; elle revient d'elle-même quand on revise un marqueur, ou via le bouton ⓘ POL-01.

⚡ Fonction

Les chaînes d'action (énergie) et d'acquisition (information). Choisir une chaîne puis ▶ Voir la chaîne sur la machine : le flux circule d'organe en organe, le bloc parcouru s'allume.

🔧 Entretien

Tous les repères de la machine. Toucher une ligne : le repère clignote. Toucher ☐ quand le point est fait (repère vert), puis Valider la tournée.

⚠ Sécurité

Procédure guidée étape par étape (ex. consignation électrique + pneumatique). Chaque Fait ✓ passe à l'étape suivante et montre l'organe concerné.

📒 Journal

Historique daté des tournées et procédures enregistrées, partageable par mail ou messagerie.

Les procédures de sécurité affichées sont des aides pédagogiques : elles ne remplacent ni la procédure de consignation de l'établissement, ni l'habilitation requise.

5. À proximité et flèche de guidage

  • Toucher un repère 3D à l'écran ouvre directement sa ligne dans l'onglet Entretien.
  • ⌖ 5 en haut : nombre de points dans le rayon choisi. Le toucher affiche la liste triée du plus proche au plus lointain ; toucher une ligne sélectionne le point.
  • Si le point sélectionné est hors de l'écran, une flèche au bord indique où tourner, avec la distance (« 1,2 m · derrière vous »).
  • Le rayon se règle dans ⚙ → « Rayon de la liste » (50 cm à 10 m).

6. Placer les repères sur la machine réelle

Les positions de départ sont approximatives : on les cale sur place, sans mètre ruban.

  1. ⚙ → Mode placement des repères.
  2. Viser le marqueur (cadre vert), puis balayer la zone de l'organe quelques secondes pour que la surface soit reconnue.
  3. Dans l'onglet Entretien, toucher 📍 à côté du point voulu : la fiche se masque.
  4. Toucher l'endroit réel de l'organe à l'écran. Message « Point n placé » : le repère s'y fixe. Les chaînes qui passent par cet organe suivent automatiquement.
  5. Une fois la machine calée : ⚙ → Exporter les positions, et envoyer le fichier à l'administrateur pour l'intégrer à tous les téléphones.
Si le message « Surface non reconnue » apparaît : bouger un peu le téléphone autour de l'organe, mieux éclairer, ou toucher une surface plus texturée juste à côté.

7. Mettre à jour

Quand une nouvelle version existe, un bandeau orange s'affiche en haut de l'appli : le toucher télécharge l'APK, puis l'ouvrir pour l'installer par-dessus. Réglages, tournées et journal sont conservés.

8. Dépannage

Le cadre n'apparaît jamais sur le marqueur

Approcher davantage (un quart de l'écran), vérifier l'éclairage et l'absence de reflet, vérifier la taille imprimée à la règle et, pour la table et le bureau, le réglage ⚙ → Taille des marqueurs.

Les repères sont décalés ou ont dérivé

Revenir viser le marqueur (cadre vert) : l'appli se recale. Sinon ⚙ → Réinitialiser le suivi. Si le décalage est toujours le même, ce sont les positions qui sont à corriger : voir Placer les repères.

« Mouvement trop rapide » ou « Pas assez de lumière »

Bouger plus lentement, éclairer la zone, éviter de viser une surface uniforme (mur blanc, tôle lisse).

« Ce téléphone n'est pas compatible ARCore »

Le téléphone n'est pas dans la liste Google. Utiliser un autre appareil compatible.

L'installation est refusée (« appli non installée »)

Vérifier qu'il reste de la place sur le téléphone. Si la version installée provient d'une autre source (signature différente), la désinstaller puis réinstaller.

La caméra ne s'ouvre pas

Fermer les autres applis qui utilisent la caméra. Vérifier l'autorisation : Paramètres Android → Applis → Atelier RA → Autorisations → Caméra.

9. Administration

Pour l'administrateur du portail.

Configurer Firebase (comptes et base de données)

  1. Sur console.firebase.google.com : Créer un projet nommé atelier-ra (Google Analytics facultatif).
  2. Icône </> (application Web) → nom portail, sans Firebase Hosting → Enregistrer. Copier le bloc firebaseConfig (non secret).
  3. Authentication → Commencer → Adresse e-mail/Mot de passe → activer.
  4. Authentication → Paramètres → Domaines autorisés → ajouter ghepito.github.io.
  5. Firestore Database → Créer → emplacement europe-west9 (Paris) → mode production.
  6. Firestore → onglet Règles : coller le contenu du fichier firestore.rules, puis Publier.

Devenir administrateur (une seule fois)

  1. Créer son compte dans l'espace connecté (sans code classe) : il est créé en « Apprenant ».
  2. Console Firebase → Firestore Database → Données → collection users → ouvrir son document (repérable à son e-mail).
  3. Modifier le champ role : remplacer apprenant par admin, puis enregistrer.
  4. Recharger l'espace connecté : les onglets d'administration apparaissent. Les collègues formateurs se créent ensuite un compte, et l'administrateur les passe en « Formateur » dans l'onglet Utilisateurs.

Premier remplissage

  1. Fiches machines → Initialiser les fiches depuis l'appli : copie les 3 fiches actuelles dans la base.
  2. Classes : créer une classe ; transmettre son code aux apprenants.
  3. Publier : les téléphones reçoivent les fiches au prochain démarrage (bandeau bleu « Fiches mises à jour »).

Publication de l'appli et du portail

Le code est sur GitHub. Chaque modification recompile automatiquement l'APK (onglet Actions) et met à jour ce portail (GitHub Pages).
